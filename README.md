# 🍽️ CraveLoop Dine

### A Smart & Interactive Online Food Ordering Platform

CraveLoop Dine is a modern and interactive **online food ordering web application** designed to provide users with a convenient and engaging food ordering experience.

The platform allows users to explore different cuisines, search for dishes, add items to their cart, complete the payment process and track their orders. It also includes an **admin dashboard** for managing dishes, users, orders and reviews.

---

## 🌟 Project Overview

CraveLoop Dine brings multiple food ordering features together in one platform.

Users can explore:

🍛 **North Indian Cuisine**
🥘 **South Indian Cuisine**
🍕 **Italian Cuisine**
🥡 **Chinese Cuisine**

The application focuses on creating a simple, interactive and user-friendly experience from **food discovery to order tracking**.

---

## ✨ Key Features

### 🔍 Smart Food Search

Users can search for dishes and quickly find the food they are looking for.

### 🍽️ Multiple Cuisines

The application provides different cuisine categories:

* North Indian
* South Indian
* Italian
* Chinese

Each cuisine contains a variety of dishes with their respective prices and details.

### 🛒 Shopping Cart

Users can:

* Add dishes to the cart
* Remove dishes
* Update quantities
* View total price
* Continue to payment

Cart information is maintained using **LocalStorage**.

### 💳 Payment System

The payment page provides:

* Ordered item summary
* Delivery charges
* GST calculation
* Total payable amount
* QR-based payment interface
* Order confirmation

### 📦 Live Order Tracking

After confirming an order, users can track the order through different stages:

**Waiting for Confirmation → Preparing → Packing → Out for Delivery**

### 👨‍💼 Admin Dashboard

The admin dashboard provides management features for:

* Dishes
* Users
* Orders
* Reviews
* Availability / stock status

The dashboard also provides useful statistics about the application.

### 🌦️ Weather-Based Smart Menu

The project includes a concept for recommending suitable food based on current weather conditions using a weather API.

### 😊 Mood-Based Food Suggestions

The application also includes a mood-based food recommendation concept that suggests food according to the user's selected mood.
